# Niltavi UI repository guidance

Before proposing or making changes, load the [Niltavi project Skill](.agents/skills/niltavi-project/SKILL.md).
Read and follow the current [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme), then consult
[Niltavi Skills](https://github.com/niltavi/niltavi-skills#readme) and
[Niltavi UI](https://github.com/niltavi/niltavi-ui#readme) in that order, as the Skill directs.

For UI work, also follow the [Niltavi UI Skill](skills/niltavi-ui/SKILL.md) in this repository.
